# Project skills

Skills in this folder are available to the agent for this repo.

| Skill | When it applies |
|-------|-----------------|
| `frontend-design` | UI, landing pages, visual design, branding, layout |
| `ui-ux-pro-max` | Professional UI/UX design intelligence (styles, palettes, Flutter/mobile stacks) |

Installed Cursor plugins (Superpowers, Supabase, Datadog, Browserbase Functions, Cursor SDK, CLI for Agents, Agent Compatibility) also contribute skills automatically when relevant.

**Not installed (wrong stack for Flutter):** Vercel React Native Skills, Web Design Guidelines, React Best Practices, Composition Patterns — those target React/Next/RN, not Flutter.
